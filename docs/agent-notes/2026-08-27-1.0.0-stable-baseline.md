# 1.0.0 Stable Baseline and Deferred Stage E

Release `1.0.0` declares the existing self-contained stable ACP v1 integration production-ready without expanding its advertised capabilities. Stages A, B, C, and D1 define the supported baseline: stable-v1 protocol negotiation, the reviewed editor-profile closure, session-scoped MCP, and durable non-destructive session close with real multi-process recovery coverage.

## Stage E decision

Stage E, “Rich Content and Real-Time UI,” is `Deferred`. Its terminal streaming, audio, embedded-resource, richer diff, plan-operation, compaction-presentation, notice, and large-content work is not required for correct core ACP v1 operation. Several items also depend on draft protocol surfaces, Zed support, or new owning Harness domain capabilities. Shipping partial transport-only substitutes would violate the repository's capability-composition and durable-replay boundaries.

Deferred means there is no active release commitment. An item may be reconsidered when concrete editor demand exists and its protocol, Harness Service Definition/Provider/Consumer composition, persistence, replay, cancellation, and ownership lifecycle are complete. Correctness defects in already-supported generic projection remain in scope and do not require reactivating the whole stage.

## Compatibility and versioning

The major release changes package and ACP `agentInfo` versions to `1.0.0`. It intentionally preserves the `0.8.1` capability advertisement and runtime behavior: unsupported audio, embedded context, session deletion, and additional directories remain unadvertised or explicitly rejected. No Harness domain behavior moves into the ACP transport.
