# Upstream 0.1.5-rc.3 Baseline

The composed Harness baseline moves from `0.1.5-rc.1` to `0.1.5-rc.3`. The advertised ACP surface and runtime behaviors remain completely aligned: `@agentclientprotocol/sdk` stays at `1.4.0`, and the official `@deepseek-ai/dsh-acp` publishes the exact same twelve spec files with zero diff compared to `0.1.5-rc.1` (and `codec.spec.ts` remains byte-identical to `0.1.2-rc.1`).

## Upstream Changes Between 0.1.5-rc.1 and 0.1.5-rc.3

A complete git diff across `dsh-v0.1.5-rc.1..dsh-v0.1.5-rc.3` reveals that changes were concentrated in web client deliverables and vendor packaging:

1. **Web deliverables and feedback dialog backports** (`060323d8e`):
   - Refinements to feedback categories and dialog UI in `@deepseek-ai/dsh-client-ui-message-feedback`.
   - File type icons and tail spacing in `@deepseek-ai/dsh-client-ui-deliverables` and `@deepseek-ai/dsh-client-ui-chat`.
   - None of these packages are in the ACP server composition.
2. **Vendor dependency pinning** (`943af81a1`):
   - Internal dependencies across the upstream monorepo packages (such as `@deepseek-ai/schemastery`, `@deepseek-ai/cordis`, and `@deepseek-ai/cordis-plugin-*`) were pinned from `workspace:^` to `workspace:*` to prevent version drift during package publishing.
3. **No runtime or protocol changes**:
   - Zero changes to the agent loop, session persistence format (v3), tools, subagents, prompt engines, or ACP adapter source.
   - All twelve official ACP specs remain identical to `0.1.5-rc.1`.
